# Tools for FluentCart

## English

![Tools for FluentCart](assets-github/banner-github-en.png?v=20261007-centered)

**Fine-tune your store.**

Practical tools for your FluentCart shop. The Cart Rules module provides single-item carts, minimum quantities and merchandise value, maximum quantities, and quantity steps.

Version 0.9.1 is available.

[Repository](https://github.com/deckerweb/tools-for-fluentcart) · [Documentation](https://github.com/deckerweb/tools-for-fluentcart/wiki/Documentation) · [Download 0.9.1](https://github.com/deckerweb/tools-for-fluentcart/releases/download/v0.9.1/tools-for-fluentcart-0.9.1.zip)


Known upstream limitation in FluentCart 1.7.0: When creating a new website in a Multisite network, the FluentCart scheduler can report database errors because the required tables are not yet available. This issue originates in the parent plugin FluentCart 1.7.0. Tools for FluentCart documents the limitation and does not modify FluentCart to address it.

## Deutsch

![Tools for FluentCart](assets-github/banner-github-de.png?v=20261007-centered)

**Dein Shop. Fein abgestimmt.**

Praktische Werkzeuge für deinen FluentCart-Shop. Das Modul Cart Rules bietet Ein-Artikel-Warenkörbe, Mindestmengen und Mindestwarenwert, Höchstmengen und Mengenschritte.

Version 0.9.1 ist veröffentlicht.

[Repository](https://github.com/deckerweb/tools-for-fluentcart) · [Dokumentation](https://github.com/deckerweb/tools-for-fluentcart/wiki/Dokumentation) · [Download 0.9.1](https://github.com/deckerweb/tools-for-fluentcart/releases/download/v0.9.1/tools-for-fluentcart-0.9.1.zip)


Bekannte Einschränkung in FluentCart 1.7.0: Beim Anlegen einer neuen Website in einem Multisite-Netzwerk kann der FluentCart-eigene Scheduler Datenbankfehler melden, weil die benötigten Tabellen zu diesem Zeitpunkt noch nicht vorhanden sind. Die Ursache liegt im Mutter-Plugin FluentCart 1.7.0. Tools for FluentCart weist auf diese Einschränkung hin; das Add-on verändert FluentCart dafür nicht.
